# Striver A2Z DSA Journey

A structured JavaScript workspace for completing [Striver's A2Z DSA Sheet](https://takeuforward.org/dsa/strivers-a2z-sheet-learn-dsa-a-to-z). Every sheet problem has its own source file, grouped in the same learning order as the official curriculum.

## How to use

1. Open the next unchecked problem below.
2. Read the linked problem and write the solution in its corresponding `.js` file.
3. Run locally: `node path/to/problem.js`.
4. Run and test the solution, then change `[ ]` to `[x]` in this README.
5. Commit progress with a focused message such as `solve(arrays): two sum`.

> The sheet changes over time. This repository was generated from the official curriculum on 2026-09-08.
