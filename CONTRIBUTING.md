# Contributing

Keep each problem solution in its existing file. Before committing:

- explain the approach and complexities in the file header;
- run with a current Node.js LTS release;
- test normal, boundary, and edge cases;
- mark the matching README checkbox only after the solution passes;
- keep each solution self-contained and dependency-free unless a dependency is truly required.

Use focused commit messages, for example: `solve(binary-search): search in rotated array`.
